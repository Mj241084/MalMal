# فاز P11 — محصولات، دسته‌ها و برندها

**هدف:** استودیوی محصول که سردرگمی فعلی (عکس، تنوع، مشخصات، slug) را برطرف می‌کند.

## مطالعه
- `docs/09-panel-spec.md` ماژول‌های ۴، ۵، ۶ و بخش ۲.۷
- `apps/catalog/*`، `apps/core/html.py`
- `docs/03-data-model.md` بخش ۵ (کش و باطل‌سازی)

## کارها
1. اصلاح EXIF در `images.generate_webp_sizes` + تست.
2. `catalog/specs.py`: `applicable_attributes(category)` + تست زنجیره‌ی ارث‌بری.
3. فهرست محصولات (فیلتر، جستجو، ویرایش سریع، اکشن دسته‌جمعی).
4. ساخت دو مرحله‌ای (D39) و استودیو (اطلاعات، گالری، تنوع، مشخصات، سئو، انتشار) طبق ماژول ۴.
5. قواعد حذف (D45)، چک‌لیست انتشار.
6. `[OPEN]` ویرایشگر متن غنی (D46): نمونه‌ی کوچک بساز، یافته‌ها را بگو و قبل از اتصال تایید بگیر. اگر تایید نشد textarea.
7. دسته‌ها (درخت، فرم، ↑↓، تب مشخصات)، برندها.
8. provider جستجوی محصول.
9. گسترش `setup_groups` در صورت نیاز.

## خارج از این فاز
موجودی دستی (P12)، ایمپورت CSV.

## تست‌ها
- ماتریس باطل‌سازی از مسیر پنل: تغییر قیمت ← `rev` و `subtree_rev`؛ تغییر دسته ← زنجیره‌ی قدیم و جدید؛ تغییر برند/alias ← `search_text` و FTS؛ تغییر تصویر اصلی؛ حذف تصویر اصلی (ترتیب) ← کش لیست تازه.
- مقدار عددی مشخصه هر دو ستون را پر می‌کند.
- تنوع دارای `StockMovement` حذف نمی‌شود.
- فعال‌سازی بدون چک‌لیست رد می‌شود.
- sanitize توضیحات.
- آپلود نامعتبر/بزرگ رد می‌شود.
- slug یکتا.
