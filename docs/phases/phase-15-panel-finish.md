# فاز P15 — تکمیل پنل و بازنشسته‌کردن ادمین برای کار روزانه

**هدف:** پنل تنها ابزار روزانه شود و کیفیت نهایی تایید شود.

## مطالعه
- `docs/09-panel-spec.md` کامل (به‌ویژه ۲.۵ و ۲.۸) و `docs/10-panel-ui.md`
- `docs/deploy.md` و `docs/00-README.md` بخش ۷ (چک‌لیست انتشار)
- اسکیل `unslop` (چک‌لیست انتهای آن)

## کارها
1. داشبورد نهایی (همه‌ی بلوک‌ها با لینک‌های پنل؛ حذف همه‌ی `[TEMP]`)، جستجوی سراسری کامل، بج‌ها.
2. تست‌های نقش‌محور: با هر گروه (محتوا، فروش، نظرها، مدیر کل) فقط بخش‌های ماتریس ۲.۵ دیده می‌شود. هر لینک ناوبری برای نقش مربوطه ۲۰۰ و برای بقیه ۴۰۳ است.
3. پاس عملکرد: بودجه‌ی query برای هر لیست و داشبورد، بدون N+1.
4. پاس دسترس‌پذیری/کیبورد، و چک‌لیست `unslop` روی داشبورد، سفارش، استودیوی محصول.
5. ادمین: لینکش فقط برای superuser. بقیه‌ی ادمین دست‌نخورده می‌ماند.
6. `docs/deploy.md` (راه‌اندازی اولین کارمند، `setup_groups` پس از هر استقرار با مجوز تازه) و `docs/panel-guide.md` (راهنمای کوتاه روزانه‌ی کارمند: پردازش سفارش، ثبت ارسال، بازگشت وجه، تغییر موجودی، افزودن محصول).
7. دودی دستی انتها‌به‌انتها با کاربر: ورود ← سفارش پرداخت‌شده ← آماده‌سازی ← ارسال با رهگیری ← پیامک ← تحویل؛ و محصول تازه با عکس/تنوع/مشخصات ← فعال‌سازی ← دیدن در فروشگاه.

## خارج از این فاز
هر آنچه در `09` بخش ۲.۹ آمده (گزارش فروش، ثبت دستی سفارش، ویرایش آدرس سفارش و...).
